# Ruben Caleb Portfolio

A personal portfolio built to showcase projects, technical skills, ideas, experiments, and the ongoing evolution of my journey as a software developer.

Rather than serving as a static résumé, this project is designed as an interactive digital workspace where visitors can explore:

- Featured projects
- Technical skills and technologies
- Development notes and experiments
- Personal thoughts on software and technology
- Ideas under exploration
- Career and learning milestones

---

## Philosophy

This portfolio is built around a simple idea:

> Show the work. Show the thinking.

Projects demonstrate execution.

Ideas reveal curiosity.

Notes document learning.

Together they provide a more complete picture than a traditional portfolio.

---

## Sections

### Home

Introduction, background, and current focus.

### Projects

A collection of completed and ongoing software projects.

### Technologies

Tools, frameworks, languages, and platforms used throughout development.

### Thoughts

Articles, observations, and reflections on software engineering, technology, and learning.

### Evolution

A timeline documenting growth, milestones, and major learning moments.

### Ideas

Concepts, product ideas, and experiments that may eventually become projects.

### Notebook

A collection of technical notes, research, references, and development discoveries.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Motion
- Lucide Icons

Additional technologies may be added as the project evolves.

---

## Goals

- Create a portfolio that feels alive rather than static.
- Document technical growth publicly.
- Showcase both completed work and the thinking behind it.
- Experiment with modern UI, animation, and interaction patterns.
- Maintain a space for continuous learning and exploration.

---

## Development

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
